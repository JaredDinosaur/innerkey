# innerkey
If your machine is from an OEM, such as Dell, Lenovo, or HP, there is a good chance that it has a Windows product key embedded in its firmware.\
If a key exists, it is present no matter what OS you're using. This script allows you to retrieve the key from Linux.\
You can check which version of Windows a key is for here: https://mskey.in/pid-key-checker-for-office-windows-license-key/

You can run the following command in your terminal to execute the script:
```bash
curl -fsSL https://raw.githubusercontent.com/JaredDinosaur/innerkey/refs/heads/main/innerkey.sh | bash
```
